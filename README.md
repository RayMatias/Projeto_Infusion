# 🧭 StoryCompass - Descubra sua próxima leitura

Um catálogo digital elegante e responsivo, focado na exibição de livros, categorias, e novos lançamentos literários. Este projeto é uma **aplicação estritamente Front-End**, desenvolvida para aplicar conceitos avançados de estruturação de layouts, UI/UX e boas práticas de codificação.

## 💻 Sobre o Projeto

O StoryCompass foi projetado com uma interface moderna em Dark Mode para proporcionar uma experiência visual agradável e imersiva aos leitores. O foco técnico principal desta versão foi a construção de uma base CSS sólida, escalável e de fácil manutenção, utilizando metodologias de mercado e abandonando layouts engessados.

## 🛠️ Tecnologias e Conceitos Utilizados

*   **HTML5 Semântico:** Focado em acessibilidade e estrutura clara.
*   **CSS3 (Avançado):**
    *   **CSS Grid Customizado:** Criação de um sistema de grid de 12 colunas (`.grid-cols-12`) reutilizável, permitindo alinhamentos precisos e responsividade inteligente.
    *   **Metodologia BEM (Block, Element, Modifier):** Nomenclatura de classes rigorosa para evitar conflitos de estilo e facilitar a leitura do código.
    *   **Variáveis CSS (`:root`):** Gerenciamento centralizado da paleta de cores (Dark Theme) e tipografia.
*   **JavaScript (Vanilla):**
    *   Manipulação do DOM.
    *   Lógica de alternância (Toggle) para o menu.
    *   Atualização dinâmica de atributos ARIA (`aria-expanded`) para garantir a acessibilidade de leitores de tela.

## 🌟 Funcionalidades Principais

*   **Menu Off-Canvas Universal:** Uma gaveta de navegação lateral fluida que sobrepõe o conteúdo. Este padrão de design moderno foi aplicado tanto para a versão mobile quanto para desktop, maximizando a área de foco do usuário no conteúdo principal.
*   **Design Responsivo:** Adaptação fluida de componentes, como a grade de livros em destaque e a organização da "Hero Section", garantindo legibilidade em qualquer dispositivo.
*   **Componentização Visual:** Cards de livros reutilizáveis com efeitos de *hover* e *scale* suaves para melhorar a interatividade e a resposta tátil visual.
